使用Java来操作Excel 使用两种方式:Excel poi EasyExcel

1. poi引入依赖
```xml
<dependency>
    <groupId>org.apache.poi</groupId>
    <artifactId>poi</artifactId>
    <version>5.2.4</version>
</dependency>
```
2. HSSF: 处理Excel 97-2003格式(.xls)
   XSSF: 处理Excel 2007+格式(.xlsx)
   SXSSF: 大数据量Excel写入的流式API
3. Workbook (工作簿)
   └── Sheet (工作表)
   └── Row (行)
   └── Cell (单元格)



使用EasyExcel
1. 引入依赖
```xml
<dependency>
    <groupId>com.alibaba</groupId>
    <artifactId>easyexcel</artifactId>
    <version>3.3.2</version>
</dependency>
``` 
2. 数据模型定义

```java
@Data
@AllArgsConstructor
@NoArgsConstructor
public class Employee {
    @ExcelProperty(value = "员工ID", index = 0)
    private Integer id;
    
    @ExcelProperty(value = "姓名", index = 1)
    private String name;
    
    @ExcelProperty(value = "部门", index = 2)
    private String department;
    
    @ExcelProperty(value = "薪资", index = 3)
    @NumberFormat("#.##")
    private Double salary;
    
    @ExcelProperty(value = "入职日期", index = 4)
    @DateTimeFormat("yyyy-MM-dd")
    private Date joinDate;
}
```

# Java Arsenal 项目

这是一个通用的 Java 项目集合，包含多个子模块和示例代码。

## 项目结构

- `consumer_boot`: Spring Boot RabbitMQ 消费者示例
- `core_se`: Java 核心技术示例

## 模块说明

### consumer_boot
基于 Spring Boot 的 RabbitMQ 消费者实现，包含：
- RabbitMQ 配置
- 消息监听器
- 消息处理服务

### core_se
Java 核心技术示例，包含：
- Record 类型示例 (NES.java)

## 使用说明

请根据具体模块的需求进行构建和运行。

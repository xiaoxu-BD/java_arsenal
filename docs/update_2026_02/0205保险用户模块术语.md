# 保险用户模块术语

维护投保人个人信息的脱敏处理和加密安全数据处理;对接用户实名认证接口

## 项目背景:
由于监管要求在日常调试和生产环境中不能看到用户的真实信息，
要求不能在日志中看到用户的基本信息比如身份证号／营业执照等
在日志中要求进行脱敏处理：　
对接实名认证接口/对接脱敏处理

```text
公司提供了统一的安全基础设施，我的工作是在承保场景中精准落地：
通过 MyBatis 拦截器 实现透明加密，确保入库即密文；
 基于 RBAC + AOP 实现角色化脱敏，满足核保与客服不同视图需求；
用 Hystrix 熔断 保障 KYC 服务异常时系统可用；
最终通过 JMeter 压测 + 日志审计 验证性能与合规双达标。
```

所用到的技术: mybatis 自定义映射器(TypeHandler)
            脱敏组件; github脱敏组件

核心规则
  • 基本类型复制"值"：name、age 各改各的，永不互相影响
  • 浅拷贝复制"地址"：friend 字段两羊指向同一个对象 —— 一方改名，另一方跟着变（上面试试）
  • 深拷贝才彻底独立：引用字段也重新造一份；工程上推荐序列化深拷贝（见 advanced/prototype 包）
什么时候用原型？对象创建成本高（查库、大量计算）且新对象与模板大体相同时，clone 比重新 new+赋值划算。
代码联动
public class Sheep implements Cloneable {
    private String name;
    private int age;
    private Friend friend;          // 引用类型：考点！

    @Override
    public Sheep clone() {          // 浅拷贝
        return (Sheep) super.clone();
        // friend 只复制了地址 → 两羊共享同一个朋友
    }

    public Sheep deepClone() {      // 深拷贝
        Sheep copy = clone();
        copy.friend = new Friend(this.friend.getName());
        // 朋友也重新造一个 → 彻底独立
        return copy;
    }
}

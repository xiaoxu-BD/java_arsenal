模板方法 Template Method 行为型

一句话核心：final 锁死流程骨架，差异步骤留给子类填空，钩子方法还能反过来影响流程走向

交互舞台 · make() 一键冲饮品（蓝色=父类锁死，橙色=子类填空）
步骤会依次亮起 —— 顺序永远改不了
核心规则
  • 骨架 final：make() 的 1→2→3→4 顺序由父类锁死，子类想调换步骤？门都没有
  • 填空式扩展：子类只实现 brew()/addCondiments() 两个差异步骤，通用步骤父类复用一份
  • 钩子影响流程：wantCondiments() 返回 false 时第 4 步被跳过 —— 子类能"轻度"控制模板走向
JDK 同款：AbstractList 定规则、ArrayList 填实现；AQS、JdbcTemplate 同思路 （不依赖继承的"回调版模板"见 advanced/template 包）。
代码联动 · 步骤亮起时对应行高亮
public abstract class DrinkTemplate {

    public final void make() {              // 模板方法：final 锁流程
        boilWater();                        // ① 通用：父类实现
        brew();                             // ② 差异：子类填空
        pourInCup();                        // ③ 通用：父类实现
        if (wantCondiments()) {             // ④ 钩子：默认 true
            addCondiments();                //    差异：子类填空
        }
    }

    private void boilWater() { }             // 固定步骤
    private void pourInCup() { }             // 固定步骤
    protected abstract void brew();          // 填空
    protected abstract void addCondiments(); // 填空
    protected boolean wantCondiments() {     // 钩子
        return true;
    }
}

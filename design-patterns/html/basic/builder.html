建造者模式 Builder 创建型

一句话核心：多可选参数的对象分步构建 —— 链式具名调用，build() 一次成型、不可再改

交互舞台 · 配一台电脑（左侧操作，右侧代码同步生成）
还是"半成品"：Builder 正在收集参数，Computer 对象尚不存在
✗ 重载构造器（伸缩式）选项组合爆炸要写 N 个构造器；new Computer("i5",16,512,true) —— 第 4 个参数是什么意思？传串位编译器也不报错
✓ 建造者new Builder("i5").memory(16).build() 每个值具名可读；必填项放构造器想漏都漏不掉；成型后全字段 final 不可变
核心规则
  • 必填进构造器：CPU 放在 Builder(String cpu) 里，漏配编译都过不了
  • 可选项给默认值：不显式设置也有兜底，链式调用返回 this
  • build() 才真正成型：一次性 new 出全 final 的不可变对象——没有 setter，多线程共享零风险（JDK 同款：StringBuilder）
代码联动 · 链式调用实时生成
Computer pc = new Computer.Builder("i5")   // 必填：CPU
        .memory(16)                          // 可选：内存
        .disk(512)                           // 可选：硬盘
        .gpu(true)                           // 可选：独显
        .build();                            // 一次成型，此后不可改

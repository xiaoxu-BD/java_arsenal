责任链模式 Chain of Responsibility 行为型

一句话核心：请求沿链传递，处理者"能批就批、批不了传下家" —— 申请人只认识入口，不知道最终谁批

交互舞台 · 提交一张请假单（拖天数 → 提交 → 看单子停在哪）

核心规则
  • 一人一岗一权限：每个 Handler 只写自己的审批规则（组长只比 1 天），超过就传给 next
  • 发起方只认识入口：申请人把单子递给组长，不关心后面有几个人、最终谁批
  • 动态组链：setNext 串链；加一级"HR 总监"只需新增一个类接在链尾，其余不动
日常同款：Servlet Filter、网关过滤器、Netty Pipeline。 工程版"双向拦截链"（OkHttp 拦截器，请求下行/响应上行）见 advanced/chain 包。
代码联动 · 单子路过时高亮对应行
public abstract class Approver {
    protected Approver next;                        // 下一个处理者

    public Approver setNext(Approver next) {        // 串链
        this.next = next;
        return next;                                // 返回下家，支持连缀
    }

    public abstract void handle(LeaveRequest req);  // 能批就批
}

public class GroupLeader extends Approver {
    public void handle(LeaveRequest req) {
        if (req.getDays() <= 1) {
            System.out.println("组长批准");          // 我的权限内
        } else if (next != null) {
            next.handle(req);                       // 传给下家
        }
    }
}

外观模式 Facade 结构型

一句话核心：给复杂子系统一个总开关 —— 客户端只需要"看电影"，不必记住 3 台设备的开关顺序

交互舞台 · 想在家看个电影

核心规则
  • 收口不改造：门面不改子系统的任何代码，只是把"多步操作+顺序"编排成一个简单入口
  • 最少知识原则：客户端只认识 watchMovie/endMovie 两个词，与 3 个子系统解耦
  • 编排是门面的责任：真实项目里下单门面还负责异常语义翻译、扩展新步骤（见 advanced/facade 的 OrderFacade）
日常同款：日志门面 slf4j（背后 Logback/Log4j 随便换）、应用层 AppService。
代码联动
public class HomeTheaterFacade {
    private final Projector projector = new Projector();
    private final Screen screen = new Screen();
    private final SoundSystem soundSystem = new SoundSystem();

    public void watchMovie() {          // 一键观影
        screen.down();                  // ① 幕布降下
        projector.on();                 // ② 投影仪开机
        soundSystem.on();               // ③ 音响开机
    }

    public void endMovie() {            // 一键关闭（顺序还得反过来记）
        soundSystem.off();
        projector.off();
        screen.up();
    }
}

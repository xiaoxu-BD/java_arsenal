策略模式 Strategy 行为型

一句话核心：一族可互换的算法 —— 上下文把"怎么做"委托出去，运行时随时换，新增算法零修改

核心规则
  • 组合替代继承：Traveler 持有一个 TravelStrategy 字段，而不是继承出 PlaneTraveler/TrainTraveler… 一堆子类
  • 运行时可换：setStrategy() 随时切换，同一个 travel() 调用行为完全不同
  • 开闭原则：新增出行方式只加一个实现类，Traveler 一行不改（点左侧"需求变更"试试）
JDK 同款：Collections.sort(list, comparator) —— comparator 就是一个可插拔策略。 工程落地：策略 + 注册表工厂消除 if-else（见 advanced/factory 包）。
代码联动
public class Traveler {                   // 上下文
    private TravelStrategy strategy;      // 组合：一族算法

    public void setStrategy(TravelStrategy s) {
        this.strategy = s;                // 运行时换策略
    }

    public void travel(int distanceKm) {
        // 委托：怎么走完全是策略的事，本类零感知
        System.out.println("选择[" + strategy.name()
            + "] 出行 " + distanceKm + "km，预计 "
            + strategy.costHours(distanceKm) + " 小时");
    }
}

public class PlaneStrategy implements TravelStrategy {
    public int costHours(int km) { return Math.max(1, km / 800); }
    public String name()       { return "飞机"; }
}

public class EbikeStrategy implements TravelStrategy {   // ✓ 新增
    public int costHours(int km) { return km / 25; }
    public String name()       { return "电动车"; }
}
